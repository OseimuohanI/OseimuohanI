## What I've Been Building

- **[HTTP/1.1 Server](https://github.com/OseimuohanI/HTTP-1.1)** — an HTTP/1.1 server built straight on TCP sockets in C, no libraries, just raw networking.
- **[Agent](https://github.com/OseimuohanI/Agent)** — a Python project exploring agent-based workflows.
- **SongSync** — a Go/Wails desktop app that reads and cross-references EasyWorship's SQLite database against a lyrics bank to speed up song imports for church AV setups.
- **[Resource Management System](https://github.com/OseimuohanI/Resource-Management-System)** — a full-stack app built with Laravel and React/TypeScript.
- **Sentiment analysis for e-commerce performance** — my final year project: a Python/FastAPI NLP microservice using a marker-based router ensemble, paired with a Laravel backend, to predict how Nigerian e-commerce businesses are performing from customer sentiment.
- **[Student Disciplinary System](https://github.com/OseimuohanI/Student-Disciplinary-System)** — a PHP-based system for managing student disciplinary records.
- **[MailHog](https://github.com/OseimuohanI/MailHog)** — a web and API-based SMTP testing tool.
- **[Premiere Electric](https://github.com/OseimuohanI/Premiere-Electric)** — a full-stack Bootstrap + C# business site.
- **[Uninformed Search Strategies](https://github.com/OseimuohanI/CSC-309)** — an interactive Python walkthrough of classic AI search algorithms.
